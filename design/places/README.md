# 지명표 원본 (위치 → 가까운 지명)

- `sigungu.csv`: 시·군·구 256곳 (2026-10 OpenStreetMap 행정 경계 기준)
  - 일반구가 있는 시(수원·성남 등 13곳)는 시 대신 일반구를 넣었다 ("성남 분당구").
  - 특별시·광역시의 구는 시 이름을 붙였다 ("서울 중구", "광주 동구").
  - 좌표는 경계 다각형의 무게중심. 섬 지역(옹진군·울릉군)은 가장 큰 섬의 무게중심.
- `mountains.csv`: 산림청 100대 명산 (2002 선정, 위키백과 목록)
  - 좌표는 위키데이터. 25 덕항산·29 두타산·44 백운산(정선)·91 팔봉산은 OSM 정상 좌표로 바로잡았다.
