# Sunset Margin — 일몰 전 도착 여유 데이터 필드 (Instinct 3 Solar)

## 표시
- `+1:23` 지금 페이스면 일몰 1시간 23분 전에 목적지 도착
- `-0:15` 일몰 15분 뒤 도착 예상 (헤드랜턴 준비 / 경로 단축 검토)
- `~2:10` 코스 내비게이션 중이 아님 → 일몰까지 남은 시간만 표시
- `NO GPS` 위치를 아직 못 잡음

여유가 설정값(기본 30분) 아래로 떨어지면 한 번 진동 + 알림음.

## 계산 방식
예상 시간 = 남은거리 ÷ 평지속도 + 남은 상승고도 ÷ 시간당 상승고도  (나이스미스 규칙)
1km·15분 이후부터는 "지금까지 실제 걸린 시간 ÷ 같은 공식의 예측값"을 계수로 곱해
내 실제 페이스(배낭 무게, 휴식 습관 포함)로 자동 보정.

## 한계
- 남은 상승고도는 "목적지 고도 − 현재 고도"만 봄. 오르내림이 많은 능선이면
  실제 누적 상승보다 작게 잡혀 낙관적으로 나올 수 있음 → 그런 코스는
  시간당 상승고도 설정을 낮게(예: 300) 잡는 게 안전.
- 코스에 고도 정보가 없으면 거리만으로 계산.
- 일몰은 기기 날씨 API를 우선 쓰고, 없으면 자체 천문 계산(오차 수 분).

## 빌드 / 설치
1. VS Code + Monkey C 확장, SDK Manager에서 Instinct 3 Solar 디바이스 설치
2. manifest.xml의 product id가 SDK의 디바이스 ID와 같은지 확인
3. `Monkey C: Build for Device` → 생성된 .prg를 USB로 시계 `GARMIN/APPS/`에 복사
4. 시계: 활동(하이킹 등) 설정 → 데이터 화면 → 필드에 Connect IQ "Sunset Margin" 추가
5. 시뮬레이터 테스트: File → Playback FIT/GPX 또는 Activity Data 시뮬레이션 사용

설정(속도·상승률·경고 기준)은 Connect IQ 스토어에 올린 뒤 폰 앱에서 변경 가능.
